## Ten risks that decide the port order

1. **MPC bounds changed.** NEW restores `ACCEL_MIN` inside the solver while OURS still supplies `accel_clip[0]` as its lower bound. This changes the meaning of a profile or stopping floor. See the dedicated MPC analysis below. `437be91e24:selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py:374` `f77b26830f:selfdrive/controls/lib/longitudinal_mpc_lib/long_mpc.py:509`
2. **Stopping has two possible owners.** NEW force-stop synthesizes a trajectory and latches standstill in the planner. OURS has a stopping service and CAN StopReq latch. Combining both without a defined owner can change hold and release. This is an inference. `437be91e24:selfdrive/controls/lib/longitudinal_planner.py:235-242` `f77b26830f:selfdrive/controls/controlsd.py:255-262` `f77b26830f:opendbc_repo/opendbc/car/hyundai/carcontroller.py:35`
3. **Lead identity and distance semantics differ.** NEW can select radar-only and adjacent leads, and still subtracts Increased Stopped Distance from published `dRel`. OURS changes radar matching, adds lane-change surrogates, and centralizes distance semantics. `437be91e24:selfdrive/controls/radard.py:186-230` `f77b26830f:selfdrive/controls/radard.py:16` `f77b26830f:selfdrive/controls/radard.py:398`
4. **The model pipeline is incompatible by construction.** NEW selects per-model compiled directories and has legacy model adapters. OURS uses its own compiled-model runtime and tinygrad version. Preserving an ONNX file alone does not preserve behaviour. `437be91e24:selfdrive/modeld/modeld.py:262-281` `f77b26830f:selfdrive/modeld/modeld.py:22`
5. **Hyundai and panda ownership moved.** NEW puts alternative experience and safety configuration into `CarParams`, removes pandad's extra FPCP merge, changes sampled button events, and changes `CarState` and `CarController` signatures. Our live SCC takeover must be re-derived on this shape. `437be91e24:selfdrive/car/card.py:124` `437be91e24:selfdrive/pandad/panda_safety.cc:66-81` `437be91e24:opendbc_repo/opendbc/car/hyundai/carstate.py:38-44` `f77b26830f:selfdrive/car/card.py:369`
